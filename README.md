# ①課題名

マリオカートダッシュボード

## ②課題内容（どんな作品か）

- マリオカートワールドの各キャラクターとマシンのステータスを可視化したダッシュボードです。<br>キャラクターとマシンの合算ステータスも確認でき、最適な組み合わせをサポートします！

## ③アプリのデプロイURL

https://wild-river.github.io/kadai03_memo/

## ④アプリのログイン用IDまたはPassword（ある場合）

- ID: 今回なし
- PW: 今回なし

## ⑤工夫した点・こだわった点

- 初めはjsonファイルを読み込んでデータが表示されるのですが、localStorageを活用して各キャラクターやマシンのデータの追加・編集・削除を行えます。
- 管理画面テンプレート「Tail Admin」をベースに制作することにチャレンジしました。https://tailadmin.com/
- キャラクター・マシンの数値はグラフを使って表示させるようにしました。https://apexcharts.com/

## ⑥難しかった点・次回トライしたいこと（又は機能）

- Tailwind CSSで管理画面が作れると思い「Tail Admin」を使い始めたのですが、Alpine.jsという独特の書き方が分からず苦労しました。（最初はまったく分からず...AIに聞きながらがんばりました）
- コードをgitHubにアップする際にもつまづきポイントがたくさんあり大変でした。（Webpackでバンドルして、gh-pagesパッケージを使い、mainとは別のブランチでデプロイしました）
- キャラクターとマシンの組み合わせによるおすすめのコースの提案までできるようにしたかったです！
