# ①課題名

マリオカートダッシュボード

## ②課題内容（どんな作品か）

- マリオカートワールドの各キャラクターとマシンのステータスを可視化したダッシュボードです。キャラクターとマシンの組み合わせによる合算ステータスも確認でき、最適な組み合わせ選びをサポートします。

## ③アプリのデプロイURL

https://wild-river.github.io/kadai03_memo/

## ④アプリのログイン用IDまたはPassword（ある場合）

- ID: 今回なし
- PW: 今回なし

## ⑤工夫した点・こだわった点

- localStorageを活用してデータの追加・編集・削除を行えるようにしました。
- 管理画面テンプレート「Tail Admin」をベースに制作することにチャレンジ
- キャラクター・マシンの数値はグラフを使ってわかりやすいUIにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）

- Tailwind CSSで管理画面が作れると思い「Tail Admin」を使い始めたのですが、Alpine.js（HTMLに直接書けるJavaScriptフレームワーク）が組み込まれており、この使い方が分からず苦労しました。（書き方が独特で最初はまったく分からず...AIに聞きながらがんばりました）
- グラフはApexChartsというライブラリを使いました。こちらも使えるようになるまで苦労しました。https://apexcharts.com/
- キャラクターとマシンの組み合わせまではできたのですが、おすすめのコースなども提案できるようにしたかったです！
