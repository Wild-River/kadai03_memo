# ①課題名

マリオカートダッシュボード

## ②課題内容（どんな作品か）

- マリオカートワールドの各キャラクターとマシンのステータスを可視化したダッシュボードです。<br>キャラクターとマシンの合算ステータスも確認でき、最適な組み合わせをサポートします！

## ③アプリのデプロイURL

https://wild-river.github.io/kadai03_memo/

## ④アプリのログイン用IDまたはPassword（ある場合）

- ID: 今回なし
- PW: 今回なし

## ⑤工夫した点・こだわった点

- localStorageを活用して各キャラクターやマシンのデータの追加・編集・削除を行えます！
- 管理画面テンプレート「Tail Admin」をベースに制作することにチャレンジしました。https://tailadmin.com/
- キャラクター・マシンの数値はグラフを使ってわかりやすいUIにしました。https://apexcharts.com/

## ⑥難しかった点・次回トライしたいこと（又は機能）

- Tailwind CSSで管理画面が作れると思い「Tail Admin」を使い始めたのですが、Alpine.js（HTMLに直接書けるJavaScriptフレームワーク）が組み込まれており、使い方が分からず苦労しました。（書き方が独特で最初はまったく分からず...AIに聞きながらがんばりました）
- コードをgitHubにアップする際にもWebpackというツールで生成して、gh-pagesパッケージを使って...とつまづきポイントがたくさんありました。ToT
- グラフはApexChartsというライブラリを使いました。こちらもAIに色々聞きながら作り上げました。
- キャラクターとマシンの組み合わせまではできたのですが、おすすめのコースなども提案できるようにしたかったです！
